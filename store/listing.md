## App name (max 30 chars)

## Short description (max 80 chars)
Sketch floor plans by hand and export clean, scaled DXF files for CAD.

## Full description (max 4000 chars)
Sketch DXF turns a hand-drawn floor plan — on paper, traced from a photo, or
drawn straight on your phone — into a real, scaled DXF file you can open in
AutoCAD or any other CAD software.

WHY SKETCH DXF
Most sketch apps just make pictures. Sketch DXF makes drawings: every line,
circle, arc and dimension you place is a real vector entity with a real
world size, exported as a proper DXF (LINE, LWPOLYLINE, CIRCLE, ARC, TEXT)
that opens cleanly in AutoCAD, LibreCAD, QCAD, and anything else that reads
DXF.

DRAW YOUR WAY
• Trace over a photo of a hand-drawn plan or an existing blueprint
• Or draw straight from scratch on the canvas
• Line, Rectangle, Circle, 3-point Arc, Freehand pencil, Text and Dimension
  tools, all with snapping and an Ortho (0/90/180/270°) lock
• Wall mode: draw a room's inside perimeter and a second, correctly
  offset outside line is added automatically at whatever wall thickness
  you set — connected wall segments meet with a clean mitred corner

REAL-WORLD ACCURATE
• Type an exact length for any line, or use the Distance tool to calibrate
  the drawing against a dimension already marked on a background photo —
  every length you type from then on is converted through that scale
• Centimetre or millimetre units, your choice per drawing
• Per-shape colour

EDIT LIKE A CAD USER
• Trim, Extend, Offset, Fillet (sharp or radiused corners), Break, Stretch
• Window vs. Crossing selection, just like AutoCAD — drag left-to-right for
  fully-enclosed only, right-to-left to catch anything touched
• Undo/redo across every tool
• An AutoCAD-style command line (type L, C, TRIM, 'ORTHO, and more), with a
  Hide/Show toggle to get it out of the way when you don't need it
• Full-screen canvas mode for distraction-free drawing on small screens

REUSE YOUR OWN SYMBOLS
• Save any selection as a named, categorised Block (a door, a window, a
  fixture — anything you draw often)
• Search and insert it again later, scaled to match the current drawing's
  calibration or dropped in at its original size

IMPORT & EXPORT
• Export a finished sketch as a DXF file, ready for AutoCAD
• Import an existing DXF back onto the canvas to keep working on it —
  including files built from blocks (doors, windows, fixtures placed as
  AutoCAD block references), which come in fully placed and are added to
  your own Block library automatically
• Share or save the DXF straight from the app

No account, no ads, no data collection — everything you draw stays on your
device.

## Data safety section (Play Console) — suggested answers
- Does your app collect or share any of the required user data types? **No**
- Data is processed on-device only, stored in the app's local (private)
  database and file storage
- No data is transmitted to any developer-owned server (there isn't one)

  the photo is stored locally and never uploaded
